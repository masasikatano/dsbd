# このサービスは何をしているか

ETF を買うタイミングと銘柄を決めるための、**マクロ環境の一覧表**です。

ログインもサーバーもありません。GitHub 上に置いた静的ページを、GitHub Pages で公開しています。株価などの数字は、平日に GitHub Actions が Yahoo Finance から取り、JSON に書き出してリポジトリへ戻しています。ブラウザはその JSON を読んで表と小さなグラフを描きます。

売買の買いサインを自動で出す仕組みではありません。人が見るための数字と色です。

---

## 全体の流れ（1日のサイクル）

```
config/instruments.yaml   … 何を見るか（銘柄リスト）
          ↓
GitHub Actions（平日 21:30 UTC ≒ 日本時間 6:30、夏時間は 5:30）
          ↓
python -m src.update
  1. Yahoo Finance から約2年分の終値を取る
  2. 前日比・年初来・52週位置・200日乖離・1年ボラを計算する
  3. 2s10s など「差」の指標を作る
  4. docs/data/latest.json を上書きする
          ↓
main に commit & push（メッセージに [skip ci]）
          ↓
GitHub Pages が /docs を公開
          ↓
ブラウザが docs/index.html を開き、latest.json を fetch して表を描く
```

手動で同じことをするなら、手元で `python -m src.update` を実行し、`docs/index.html` を開けば同じ画面になります。

## リポジトリの役割分担

| 場所 | 役割 |
|------|------|
| `config/instruments.yaml` | 見る対象の定義。セクション、優先度、Yahoo のティッカー、単位、色の閾値 |
| `src/update.py` | 取得〜計算〜 JSON 書き出しの本体 |
| `src/providers/yahoo.py` | Yahoo Finance（`yfinance`）から終値系列を取る |
| `src/providers/fred.py` | 未実装の差し込み口。今は呼ばれず「データなし」になる |
| `src/compute.py` | 5つの指標とスプレッド、グラフ用の間引き履歴 |
| `docs/data/latest.json` | 最新のスナップショット（日次履歴は残さない） |
| `docs/index.html` | 画面。CSS と JS もこの1ファイル |
| `.github/workflows/update.yml` | 平日の自動更新と手動実行 |

仕様の細かい決定は `spec.md` にあります。このファイルは「人が動きを追う」ための説明です。

## 何を見ているか（画面の構成）

表はセクション 1〜6 です。全部常時表示で、折りたたみはありません。

1. **先進国株・新興国株・米国セクター** — 指数とセクター ETF  
2. **金利とカーブ** — 国債利回り、2s10s、クレジットスプレッド（後者はまだ欠測が多い）  
3. **商品** — 原油・金・銅など  
4. **為替** — DXY、ドル円、新興国通貨  
5. **センチメント** — VIX、暗号資産。MOVE は未接続  
6. **主要 ETF** — 米上場は価格あり。日本上場（1321 など）はティッカーの併記のみで価格は取りません

各行に優先度バッジがあります。

- **必須** — まず見る（S&P、NASDAQ、日経、TOPIX、米10年、DXY、ドル円、VIX）
- **次に見る** — セクター、商品、ETF マトリクスなど
- **上級** — 新興国、一部金利、農産物など

バッジは判断の強制ではなく、見る順番の目安です。

## データの取り方

v1 で実際に取るのは **Yahoo Finance だけ**です。

`instruments.yaml` の各行に `provider` があります。

| provider | 動き |
|----------|------|
| `yahoo`（省略時もこれ） | `symbol` を取る。失敗したら `symbol_fallbacks` を順に試す |
| `fred` | まだ API を呼ばない。行は「データなし」 |
| `derived` | 他の行の系列の差。例: 2s10s = 米10年 − 米2年 |
| `listed_jp` | 日本上場 ETF。価格は取らずティッカーだけ出す |

Yahoo は約 **2年分**の日足終値をまとめ取りします。失敗した銘柄だけ個別リトライします。1銘柄が落ちても他は続け、行は消さず `status: missing` にします。**全部失敗したときだけ**ジョブ全体を失敗にし、その場合は JSON を push しないので、サイトには前回の数字が残ります。一部成功なら新しい JSON を push します。

Yahoo のティッカー都合で、指数が取れないときは ETF で代用することがあります（例: TOPIX 欠測時は `1306.T`、MSCI EM は `EEM`）。米10年・30年は Yahoo が「×10」で返すことがあるので、水準が閾値を超えていたら 10 で割ります。

FRED（TIPS、HY-OAS、FRA-OIS、MOVE など）は、後から API キーとシリーズ ID を足せる形だけ残してあります。今は欠測が仕様です。

## 数字の意味（各行の5列）

終値の時系列を \(P_t\) として、当該市場の**直近の営業日同士**で計算します。リアルタイムではありません。表示の時刻は **日本時間（JST）**です。

| 列 | ざっくり | 定義 |
|----|----------|------|
| 最終値 | いちばん新しい終値 | \(P_n\) |
| 前日比 | 前営業日からの変化率 | \((P_n / P_{n-1} - 1) \times 100\)。利回りも v1 では％変化で統一 |
| 年初来 | その年の最初の営業日から | \((P_n / P_{y0} - 1) \times 100\) |
| 52週位置 | 高値〜安値のどこにいるか | 直近約252営業日の高安に対する位置（0〜100%） |
| 200日乖離 | 中期トレンドからの距離 | 200日移動平均からの乖離％。本数が足りなければ「—」 |
| 1年ボラ | 値動きの大きさ | 日次対数収益の標準偏差を年率化（√252） |

計算できないセルは「—」です。行ごと消しません。

派生指標:

- **2s10s** = 米10年 − 米2年（パーセントポイント）。負なら逆イールドで赤
- **10s30s** = 米30年 − 米10年

系列同士の日付を揃えて差を取り、同じ5指標も出します。片方でも欠けると missing です。

グラフ用に、約2年の終値を最大90点に間引いた `history` も JSON に入れています。ダッシュボード上部の小さな折れ線です。

## 画面の色

色は補助です。符号と数字は残してあるので、色だけに依存しません。

- **前日比・年初来・200日乖離**: 正が緑、負が赤、ゼロは地色
- **52週位置**: 色なし（数字のみ）
- **VIX**: 20未満は地色、20〜30は黄、30以上は赤
- **2s10s**: 負（逆転）なら赤
- クレジットスプレッドなどは「拡大＝赤」を config の `thresholds` で持てるが、Yahoo で値が来ない行は色なし

欠測件数はヘッダーのバナーに出ます。

## 公開の仕組み

サーバープロセスはありません。

1. リポジトリ設定で Pages を **Deploy from a branch**、ブランチ `main`、フォルダ `/docs` にする。
2. `docs/index.html` が公開 URL のトップになる。
3. ページ読み込み時、同じオリジンの `data/latest.json` を JavaScript が取得して表を組み立てる。ビルドツールやフレームワークはありません。

閲覧制限（ログイン、Private、Cloudflare Access など）はありません。想定閲覧者は本人ですが、URL を知っていれば誰でも見られます。カスタムドメインは使いません。

自動更新は `.github/workflows/update.yml` です。

- スケジュール: `30 21 * * 1-5`（UTC、平日）
- 手動: GitHub の Actions 画面から `workflow_dispatch`
- 権限: `contents: write`（JSON を `main` に push するため）
- コミットに `[skip ci]` を付け、JSON 更新で同じ workflow が再起動しないようにしています

日次の JSON 履歴は git に積みません。`latest.json` の上書きだけです。リポジトリを肥大させないためです。

## 手元で動かす

```bash
./run_local.sh
```

`run_local.sh` が venv を作り、依存を入れ、Yahoo から取って `latest.json` を更新し、`docs/` を `http://127.0.0.1:8080/` で出します。Ctrl+C でサーバを止めます。

```bash
./run_local.sh --no-serve    # 取得・計算だけ
./run_local.sh --serve-only  # 既存 JSON を配信するだけ
PORT=9000 ./run_local.sh
```

Yahoo へのアクセスが必要なので、ネットワークとレート制限の影響を受けます。

依存は `requirements.txt`（Python 3.12、`yfinance`、`pandas`、`PyYAML`）。

## 意図的にやっていないこと（v1）

- 分足・リアルタイム・WebSocket
- 売買シグナルの自動判定
- FRED の本番接続
- 日本上場 ETF の価格取得
- スパークライン以外の本格チャート、履歴の長期保管
- 認証や非公開化

指標を足す・優先度を変える・色の閾値を変えるときは、まず `config/instruments.yaml` を直し、`python -m src.update` で JSON を作り直します。画面側の列構成を変えるときは `docs/index.html` です。
